# SkyFarm Auto

浮島農場 SkyFarm（`https://phoenixruby.github.io/skyfarm/`）的 Tampermonkey 使用者腳本：自動收成、播種、賣出、澆水、抓蟲、
撿糞便與動物產物、餵動物、清雜物、採果樹、收魚、收機器成品、收蜂箱蜂蜜、長大的肉用動物出貨、扶正歪掉的裝飾、
替機器人換耗材。
原則是「成熟了、點一下就收得到的，都收」：設定作物以外的成熟作物也收（只收、不澆水、不賣），
收進倉庫的東西一律只在倉庫放得下時才收。

- `skyfarm-auto.js`：主程式（單一檔案，無相依套件）
- `skyfarm-auto.loader.github.user.js`：GitHub 版載入器（鎖定 commit＋SHA-256，貼進 Tampermonkey 即可）
- `skyfarm-auto.loader.user.js`：本機載入器（`file:///` 路徑，不進版控）

快速鍵：Alt+Shift+A 開關（預設 OFF）、Alt+Shift+S 設定作物、Alt+Shift+D 診斷、Alt+Shift+F 切換「全島輪流／只做這座」、Alt+Shift+G 開關**設定視窗**（或點標籤旁的「⚙」，見下面「設定視窗」；快速鍵都可以在視窗裡改）。功能說明見 `skyfarm-auto.js` 開頭。

## 對應的官方遊戲版號

測試對應的官方版號記錄在 [`test/GAME_VERSION.json`](test/GAME_VERSION.json)（目前：**2.67-f45aa956bf**）。
它只會在「契約測試對該版號的官方檔案全部通過」之後才更新（`npm run record-version`）。

## 測試

只用 Node 內建功能（需要 Node 22 以上），不需要 `npm install`。

| 指令 | 內容 |
| --- | --- |
| `npm test` | 單元測試（`test/unit`）＋發佈一致性測試（`test/release`），離線可跑 |
| `npm run test:contract` | 下載官方遊戲到 `.cache/game/`，確認腳本依賴的介面、選擇器、設定欄位都還在 |
| `npm run check-version` | 比對官方遊戲目前版號與測試對應的版號；不一致結束碼 1 |
| `npm run mutation` | 突變檢查：把關鍵安全判斷逐一改壞，每個都必須讓測試變紅 |
| `npm run record-version` | 契約測試全過後，記下新的官方版號 |
| `npm run verify` | 全部依序執行 |

測試結構：

- **單元測試**在 vm 沙盒裡執行腳本（只在記憶體副本結尾插入匯出，不改磁碟上的檔案），搭配假時鐘、假 DOM、
  一個模擬遊戲行為的假遊戲（`test/helpers`）。涵蓋：快速鍵與輸入面板、田地決策、賣出流程、動物與餵食、
  果樹魚池機器、地上雜物、各種暫停閘門、錯誤自動關閉、資安靜態檢查、釘住的預設值。
- **契約測試**（`test/contract`）：`contract.js` 列出腳本對官方遊戲的全部依賴；單元測試保證清單等於腳本真實依賴，
  契約測試保證官方遊戲目前還有這些東西。官方遊戲檔案只放在 `.cache/`（已忽略），不進版控。
- **發佈一致性**（`test/release`）：載入器鎖的 commit＋SHA-256 必須和那個 commit 裡的檔案相符、版本號一致。

## 修改流程（重要）

1. **先確認官方版號**：`npm run check-version`。
   - 一致 → 直接做新需求。
   - 不一致（遊戲更新了）→ **先調整測試**：`npm run test:contract` 看哪裡不符，修正 `test/` 內的假遊戲、
     假 DOM、契約清單（必要時再修腳本），再 `npm run record-version` 記下新版號；然後才做新需求。
2. 改程式，同時補測試。
3. **commit 前先用測試驗證**：`git config core.hooksPath tools/hooks` 啟用 pre-commit hook 後，每次 commit 會自動跑
   單元＋發佈一致性測試與版號檢查，沒過就取消。
4. 改了 `skyfarm-auto.js` 就是一次發佈：版本號加一 → 兩個 commit（先推主程式；再把載入器的 commit 與雜湊換成新的）→ push →
   從 GitHub 抓回來驗證雜湊。載入器的雜湊是對 GitHub 上的原始檔算的，所以 `*.js` 一律用 LF（見 `.gitattributes`）。

## 資安原則

腳本在頁面環境執行（`@grant none`），讀得到遊戲存檔，所以：不連網、不用 `innerHTML`/`eval`、
不碰遊戲的存檔與儲存空間（唯一例外：設定視窗存取**自己的一個鍵** `skyfarm-auto-settings`，見下一節）、
不在 `window` 上留物件、只接受真實按鍵、錯誤時自動關閉、遇到玩家開的視窗／選單／「擴地模式」就暫停、
絕不點農藥／升級（會花金幣的只有播種、補買飼料、買耗材，各有開關與金幣底線；買耗材還會核對確認視窗）。肉用動物只有「長大了」才出貨（遊戲規定長大後放 2 天就會死，所以收掉才對；還沒長大的絕不點）、
蜂箱只點「存著蜂蜜」的（點到空蜂箱會開出玩家的面板）。這些都有對應的測試釘住（`test/unit/09-security.test.js`、
`test/unit/10-collect-all.test.js`），突變檢查也會確認這些判斷被改壞時測試會變紅。

有意不處理的：水井（打水要看水塔剩多少空間，腳本讀不到；也不是收成）、太陽能板擦灰、垃圾站倒垃圾。

另外：倉庫裡的雜草沒有數量上限，只要拔完還剩 `weedKeepFree`（30）格空位就拔；
賣出設定的作物時會一併把倉庫裡的雜草賣掉（1 金幣一個，`sellWeedsWithCrops`，只認 `weed` 這個代號）；
空位不夠時標籤會寫「倉庫剩 N 格空位（拔雜草要保留 30 格）」。遊戲在「擴地模式」時所有點擊都被當成擴地，腳本會暫停到你結束為止。

## 多座島

擴地滿 4 塊後再擴會開新地圖「農場 2」（最多 5 座）。遊戲裡**所有島一直在運作**（作物照長、動物照生產、雜草照長），
但點擊只作用在畫面上那座；切島是點右側的「農場 N」按鈕（只換顯示的島、重新對焦鏡頭）。

- **全島輪流**（預設，`islandMode: 'all'`）：腳本自己切島。
  - 先「乾跑」規劃每座島（不點、不寫標籤、不改任何記錄）判斷有沒有事做，只切去真的有事做的島。
  - 目前這座沒事做才離開；一座島占用超過 `maxStayMs`（60 秒）、或有事做卻 `stuckMs`（15 秒）都沒做成事，也會讓出去。
  - 切過去的那個週期不動手，下個週期重新規劃（不拿舊計畫去點新的島）。
  - 切過去卻什麼都沒做成的島，暫停 `islandRetryMs`（30 秒、連續失敗加倍、最久 5 分鐘）再考慮；切不過去的也一樣。
  - 都沒事做了就回**家島**（按開始時看的那座、或你最後手動切到的那座；`returnHome`）。
  - 你手動切島時，那座就是家島，`userSwitchHoldMs`（30 秒）內不自己切走，腳本在你看的那座照常工作。
  - 你選的工具不是腳本用的四種（可能是建造、移除…）時，先切到收成工具才切島，免得你下一次點擊落在別座島上。
  - 機器人在等耗材而充電樁在別座島：會切過去換，再回家島。
- **只做畫面上這座**（`islandMode: 'current'`）：舊行為，不切島；標籤會提醒。
- **Alt+Shift+F** 在兩種模式之間切換（只存在記憶體，重新整理頁面就恢復「全島輪流」）。`skipIslands: [2]` 可以讓某座島（編號從 1 起算）
  永遠不被自動切過去；你自己看著那座時照常處理。
- 副作用：畫面會自己在島之間切換；每次切島都會重新對焦鏡頭，你自己調的縮放和平移會被重設。
- 標籤多一行「島 K/N｜全島輪流（家 H）｜切島 N 次」，小方格第三行是「島K/N」；診斷（Alt+Shift+D）列出每座島的雜草、糞便、成熟作物、
  有產物的動物數與「有沒有事做」。

## 機器人換耗材

機器人的耗材（鋸鏈、鑽頭、鏟刃、輪子、螺旋槳、滾筒、清潔刷、集塵袋）磨完就停工，頭上顯示「換耗材」。
伐木／採礦／整地機器人（重型充電樁）遊戲規定要在充電樁面板手動按「換耗材」，連倉庫有備品也不會自動換；
其他機器人倉庫有備品會自己換，沒備品就停工。腳本（`autoSwapParts`）會替你處理：

- 倉庫有備品 → 用收成工具點那種機器人的充電樁開面板，按「換耗材」（免費）。
- 沒備品 → 只在 `buyPartsWhenShort`（預設開）且買完金幣還有 `minCoinsAfterBuyParts`（100）以上時，買 1 個再換上
  （照商店單價：鋸鏈 150、鑽頭 250、鏟刃 100、輪子 50、螺旋槳 60…；一次最多 4 個，不買折扣組）。
- 遊戲花金幣前會先跳「確定要買嗎？」：腳本核對買的東西、數量、價格都和預期一樣才按「確定購買」，對不上就按「取消」，
  絕不勾「以後不再詢問」。面板用完一定關掉；只能換有那種充電樁的這座島（別座島的機器人要切過去）。
- 換不成（沒備品又不買、金幣不夠、這座島沒有充電樁…）會隔 60 秒再試，原因寫在標籤上；診斷（Alt+Shift+D）會顯示等耗材的機器人台數。

## 設定視窗

按 **Alt+Shift+G**，或點右下角最角落的 **⚙** 按鈕（標籤在它左邊）（不靠快速鍵，快速鍵被別的瀏覽器套件占用也開得了）開關設定視窗（Esc、「關閉」鈕也能關）。`CONFIG` 裡所有可以調的參數都在裡面，每個參數有名稱、說明、預設值、單位，
分成「節奏／收成與播種／賣出／澆水與抓蟲／動物與寵物／果樹魚池蜂箱機器／地上雜物／機器人／多座島」幾組：

- **改了立刻生效**（輸入框離開、勾選框一勾就套用），不用重新整理頁面；改過的會標「已改過」，每列有 ↺ 可以單獨恢復預設，
  最下面「全部恢復預設」要按兩次才會做。
- **不合的值會被擋下**：顯示原因（例如「要在 200 ～ 5000 之間」），欄位放回原本的值。有些參數彼此有關係（補貨目標不能小於低水位、
  澆到幾級不能小於開始澆的濕度），也會檢查。標示「會花金幣」的項目（補買飼料、買耗材、買寵物飼料、播種）都有金幣底線可以調。
- **會存在瀏覽器**（這個網站的 localStorage 的**一個鍵** `skyfarm-auto-settings`），下次載入自動套用；兩台電腦各自設定。
  只存「和預設不同」的值；改回預設就會從存檔拿掉；存不進去（私密視窗、額度滿）視窗會提示「只在這次載入有效」，設定仍然生效。
- **不會存**：開關（ON／OFF）、設定的作物、Alt+Shift+F 暫時切換的島嶼模式。
- **快速鍵也在視窗裡改**（最下面「快速鍵」那組）：按該列的「改」，再按下新的組合鍵就套用並存起來（Esc 取消，10 秒沒按自動取消）。
  規則：要有 Alt（可加 Shift）、不能含 Ctrl 或 Win／Cmd、按鍵只能是字母、數字、F1～F12、五個快速鍵彼此不能重複。
  如果某個組合鍵被別的瀏覽器套件占用，網頁根本收不到那個按鍵，錄的時候就按其他的。
  就算把快速鍵設到沒辦法用，**⚙ 按鈕**一定開得了視窗，可以改回來。「全部恢復預設」也會把快速鍵恢復預設。
- **資安**：讀回來時**只看設定表列出的參數**（不是照存檔裡的鍵去套，所以 `__proto__` 之類的鍵進不來），每一項都驗型別與範圍，
  不合的整項忽略；JSON 壞掉、超過 4 KB、瀏覽器不讓用儲存空間都不會丟錯，就用預設。只碰自己那一個鍵，不枚舉、不清空整個儲存空間；
  視窗內容只用 `textContent` 寫入。同一個網站的頁面程式本來就能寫這個鍵，所以才一律驗證；而且開關不存，
  就算存檔被竄改，腳本也不會自己開啟。診斷（Alt+Shift+D）的報告本來就包含目前完整的 `config`，另外列出「改過的參數名」（`customSettings`）。
- **要注意**：改動立刻套用並存檔，包括預設關閉的三項（果樹澆水、餵魚、機器投料）和各個金幣底線；快速鍵一改就生效。
  數字欄位在滑鼠滾輪一動時會自動失去焦點，避免滾輪偷偷改值。設定視窗的預設快速鍵原本是 Alt+Shift+C，因為會和其他套件衝突，改成 Alt+Shift+G。
- 新增 `CONFIG` 參數時，**必須**在腳本的 `SCHEMA` 加一項（名稱、說明、範圍）；測試會檢查兩邊的參數一模一樣。

## 貓、狗餵食

貓、狗（寵物）沒有「點牠餵食」這回事：時間到了（狗每 6 小時、貓每 8 小時，貪吃的貓 6 小時，幼犬幼貓加倍快），
遊戲自己從倉庫扣 1 份狗飼料／貓飼料；倉庫沒有就餓著（幼犬幼貓不長大、成犬成貓不工作）。
狗飼料、貓飼料只能在倉庫的「飼料商店」分頁買，所以腳本（`autoBuyPetFood`，預設開）做的是**保持庫存**：

- 庫存低於「隻數 × `petFoodLowPerPet`（4）」、或有寵物餓著且沒庫存，就開倉庫 → 飼料商店 → 買 10 份，補到每隻 `petFoodTargetPerPet`（10）份；
  一次最多買 5 次（50 份），沒補夠下個週期接著買。狗飼料 8、貓飼料 6 金幣一份。
- 會花金幣：買完金幣要還有 `minCoinsAfterBuyPetFood`（100）以上、倉庫要放得下 10 份。遊戲先跳「確定要買嗎？」確認視窗，
  腳本核對標題（「狗飼料 ×10」）、價格、金幣都對才按「確定購買」，對不上就按「取消」，絕不勾「以後不再詢問」。
- 沒進展（金幣不夠、倉庫沒空位…）會隔 `petFoodRetryMs`（60 秒）再試，原因寫在標籤上；診斷（Alt+Shift+D）會顯示貓狗隻數、餓著幾隻、飼料庫存。
- 一般動物（雞、鴨、牛…）的餵食照舊（`autoFeedAnimals`）；魚池（`autoFeedFish`）仍然預設關閉。鳥、昆蟲飼育箱、貓頭鷹用的飼料（鳥飼料、昆蟲果凍、冷凍小鼠）還沒處理。

## 右下角標籤

預設是完整資訊（作物、各項統計、上次動作、目前狀態）。點一下會縮成 52×52 的小方格（不會消失），再點一下展開：

- 小方格寫 `ON`／`OFF`，下面是開啟後累計做成幾件事（`✓33`）；開著但暫停中（視窗、選單、擴地模式…）改寫 `暫停`。
- 底色：灰＝關、綠＝運作中、琥珀＝暫停中。滑鼠移上去會顯示完整的狀態文字。
- 縮成小方格時開關鍵照常運作；要給你看的訊息（診斷結果、錯誤）會自動展開。縮小的狀態只存在記憶體，重新整理頁面就恢復完整資訊。
